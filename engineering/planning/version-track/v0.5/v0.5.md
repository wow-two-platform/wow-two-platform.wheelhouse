# v0.5 — Platform model

*Last updated: 2026-10-17*

**Status:** 🚧 In Progress · **Type:** Feature · **Started:** 2026-10-17 · **Completed:** —

### Iteration 1 — Workspaces and status

- [x] Ability to group products into workspaces
- [x] Ability to mark a product or a service active or inactive
- [x] Ability to show inactive products and services on demand

### Iteration 2 — Pins

- [x] Ability to pin workspaces, products and services
- [x] Ability to reorder pins

### Iteration 3 — Navigation and layout

- [x] Ability to navigate from a sidebar on desktop
- [x] Ability to navigate from a bottom bar on phones
- [x] Ability to see the whole portfolio on a home page
- [x] Ability to open a product on its own page
- [x] Ability to see services grouped by product and environment

### Iteration 4 — wow2 catalog

- [x] Ability to list every wow2 app in one catalog
- [x] Ability to import products from the catalog

### Iteration 5 — One manifest

- [ ] Ability to declare a product in one manifest file
- [ ] Ability to add a product without typing its images or release asset

### Iteration 6 — Settings and secrets

- [ ] Ability to see the settings and secrets each service declares
- [ ] Ability to edit settings per environment from allowed values
- [ ] Ability to see which required settings and secrets are missing

### Iteration 7 — Experience

- [ ] Ability to follow a deployment in a compact progress notification
- [ ] Ability to see rollout steps and page transitions animate
- [ ] Ability to swipe a table row on phones for its two main actions
- [ ] Ability to see an icon on each rollout step
