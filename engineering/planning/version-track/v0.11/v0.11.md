# v0.11 — Generated secrets

*Last updated: 2026-10-31*

**Status:** 🔄 In progress · **Type:** Feature · **Started:** 2026-10-31

Owner 2026-10-31: Wheelhouse makes a product's keys and client secrets itself, so no value passes through a person or
an agent; Ocharo's per-product Identity is the first consumer. Backups move to v0.13.

### Iteration 1 — Descriptor

- [x] Ability to declare `generate` on a secret key: random bytes as hex or base64url
- [x] Ability to declare `generate` as a command run from the service's own image
- [x] Ability to declare `from` on a key: another key's value or a derived key
- [x] Ability to check both in the pipelines generator, behind a new pipelines tag

### Iteration 2 — Generation

- [x] Ability to generate a missing secret at the first deploy instead of waiting
- [x] Ability to run a key's command in a one-off container on the target, without network
- [x] Ability to set a version's expiry from a generated certificate's end date
- [x] Ability to regenerate a key from the console, keeping earlier versions

### Iteration 3 — Linked keys

- [x] Ability to render a `from` key with its source's value, per environment
- [x] Ability to show a linked key's source in Settings and Secrets, read-only

### Verification

- [x] Build the backend and the frontend → no warnings, no errors
- [x] Run runner, Unit, Integration, E2E and Migrations → all pass
- [x] Run the frontend tests and `vue-tsc` → all pass
- [x] Run the pipelines generator tests → all pass, the new tag released
- [x] Deploy a rig product with a random and a command key → both stored, no wait
- [x] Read deploy logs, audit and the settings API → no generated value appears
- [x] Deploy a rig product with a `from` key → the second service gets the source's value
- [x] Generate a certificate key → the version's expiry matches the certificate
- [x] Regenerate a key in the console → a new version, the next deploy applies it
- [x] Deploy to dev, then promote to prod → both consoles healthy
- [ ] Deploy Ocharo dev with its Identity → keys generated, discovery's issuer matches
