# v0.11 — Generated secrets

*Last updated: 2026-10-31*

**Status:** 🔄 In progress · **Type:** Feature · **Started:** 2026-10-31

Owner 2026-10-31: Wheelhouse makes a product's keys and client secrets itself, so no value passes through a person or
an agent; Ocharo's per-product Identity is the first consumer. Backups move to v0.13.

### Iteration 1 — Descriptor

- [x] Ability to declare `generate` on a secret key: random bytes as hex or base64url
- [x] Ability to declare `generate` as a command run from the service's own image
- [x] Ability to declare `from` on a key: another key's value or a derived key
- [ ] Ability to check both in the pipelines generator, behind a new pipelines tag

### Iteration 2 — Generation

- [ ] Ability to generate a missing secret at the first deploy instead of waiting
- [ ] Ability to run a key's command in a one-off container on the target, without network
- [ ] Ability to set a version's expiry from a generated certificate's end date
- [ ] Ability to regenerate a key from the console, keeping earlier versions

### Iteration 3 — Linked keys

- [ ] Ability to render a `from` key with its source's value, per environment
- [ ] Ability to show a linked key's source in Settings and Secrets, read-only

### Verification

- [ ] Build the backend and the frontend → no warnings, no errors
- [ ] Run runner, Unit, Integration, E2E and Migrations → all pass
- [ ] Run the frontend tests and `vue-tsc` → all pass
- [ ] Run the pipelines generator tests → all pass, the new tag released
- [ ] Deploy a rig product with a random and a command key → both stored, no wait
- [ ] Read deploy logs, audit and the settings API → no generated value appears
- [ ] Deploy a rig product with a `from` key → the second service gets the source's value
- [ ] Generate a certificate key → the version's expiry matches the certificate
- [ ] Regenerate a key in the console → a new version, the next deploy applies it
- [ ] Deploy to dev, then promote to prod → both consoles healthy
- [ ] Deploy Ocharo dev with its Identity → keys generated, discovery's issuer matches
