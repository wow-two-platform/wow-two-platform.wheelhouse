# v0.13 — One-off commands

*Last updated: 2026-11-02*

**Status:** 🔄 In progress · **Type:** Feature · **Started:** 2026-11-02

Ocharo 2026-11-02 (Identity cutover, Wheelhouse #23): the owner runs a command once in a service's release image, with
that service's rendered settings and its database network, against a product environment — first Identity's
`admin create` for an instance's first owner, and `admin sign-in-link` if OQ-1 picks it. Control
verbs stopped at stop, start, restart and reset. Backups move to v0.14. The per-deploy settings record and the stale-key
warning (Wheelhouse #24) stay in the backlog.

### Iteration 1 — Runner

- [x] Ability to run a command once in a one-off container of a service's running release image
- [x] Ability to keep the command's label, exit code and scrubbed last line, never an argument
- [x] Ability to pass the command on stdin from the console to the target's worker, never as an argument

### Iteration 2 — API and console

- [x] Ability to submit a run as a control, prod gated by the typed target ID and a reason
- [x] Ability to audit a run by its label and reason, never a value
- [x] Ability to type a command in a service's menu and see its exit and last line

### Iteration 3 — Fixes

- [x] Fix the history naming every run "Run a command": its API model dropped the label
- [x] Fix a failed run reading as a broken environment: it now reads not applied, command failed

### Iteration 4 — Reveal once

Identity 2026-11-02: a verb may print a single-use link last, which the scrub cuts — first `admin invite`'s, a verb
the developer then dropped: invites come from Identity's console only.

- [x] Ability to keep a cut last line as printed for one read, 15 minutes, never in a job or audit
- [x] Ability to show that line once in the run dialog, then forget it

### Iteration 5 — Fixes from Ocharo's first Identity deploy

Ocharo dev 2026-11-02: Identity 0.5.12 refused to boot ("A client has no ClientId") and no config check ran.

- [x] Fix the render skipping each optional key's `default`, which the console already named as the source
- [x] Fix a release set dropping its repositories' `configCheck` items

### Iteration 6 — Run dialog, from Ocharo's bootstrap

Ocharo dev 2026-11-03: `admin create` ran twice from one dialog.

- [x] Fix a rerun keeping the last run's result and show-once button, which pointed at the earlier job
- [x] Ability to copy a run's last line, failed or succeeded, and the line shown once
