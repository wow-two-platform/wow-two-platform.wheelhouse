# Wheelhouse.Tests.Unit

*Last updated: 2026-10-15*

> Pure logic: validators, the version-state machine, product icon paths and other I/O-free rules.

- Prerequisites: the .NET SDK from `global.json`; no Docker.
- Run: `dotnet test Wheelhouse.Tests.Unit`.
- Fakes: `Fakes/` holds the product-specific fakes, built on the SDK testing helpers (in-memory repository, scripted HTTP).
